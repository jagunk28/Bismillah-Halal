# Meet to Marry — Wedding Organizer & Perencana Rundown

Platform manajemen pernikahan: rundown hari-H, pelacak vendor & anggaran, checklist tugas, serta daftar tamu digital dengan RSVP.

## Cara Menjalankan (di Cursor / lokal)

**Prasyarat:** Node.js 20 atau lebih baru.

1. Instal dependensi:
   `npm install`
2. (Opsional) Salin `.env.example` menjadi `.env.local`, lalu isi `GEMINI_API_KEY` dengan kunci API Gemini milikmu.
3. Jalankan aplikasi:
   `npm run dev`
4. Buka `http://localhost:3000` di browser.

## Perintah Lain

- `npm run build` — build produksi
- `npm run preview` — pratinjau hasil build
- `npm run lint` — pengecekan tipe TypeScript
